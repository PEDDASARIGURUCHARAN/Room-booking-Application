# StayEase — Room Booking Application

A responsive front-end room booking demo built with **HTML, CSS, and vanilla JavaScript**. It is suitable for practicing Git and GitHub workflows.

## Features
- Responsive room listing with three room types
- Guest count filtering
- Check-in and check-out date selection
- Booking form with basic validation
- Booking confirmation and cancellation
- Reservations saved in browser `localStorage`
- No backend or installation required

## Run locally
1. Extract the ZIP file.
2. Open the extracted `Room-Booking-Application` folder.
3. Double-click `index.html`, or open it with VS Code Live Server.

## Project files
- `index.html` — page structure
- `style.css` — responsive styling
- `script.js` — room filtering and booking logic
- `GIT_COMMANDS.md` — complete Git Bash workflow

## Note
This is a learning/demo application. It stores data in the browser only; it does not process payments or provide server-side booking availability.
